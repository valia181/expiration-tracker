TSK-001: Setup MVVM Architecture, SQLite Database Schema, and System Logging

• Ticket ID: TSK-001
• Title: Setup MVVM Architecture, SQLite Database Schema, and System Logging
• Type: Feature
• Requirement ID: REQ-NF-007, REQ-NF-003, Technical Constraints (Logging)
• Assignee: AI Agent
• Dependencies: None
• Description: Establish the core project structure following MVVM architecture guidelines. Define the local SQLite database schema (using Room or native SQLite) with transactional integrity to store items and global settings.
