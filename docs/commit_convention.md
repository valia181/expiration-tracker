# SDD Commit Message Convention

This project follows a strict commit message convention to reflect the type of SDD artifact or action:

* **spec:** Changes or additions to system specifications, concepts, and requirements.
* **test:** Adding or modifying automated tests.
* **feat:** Implementation of functionality or source code modifications.
* **docs:** Updates to documentation, agent logs, or project conventions.
* **gate:** Milestones logging, architectural decisions, and conflict resolutions.
